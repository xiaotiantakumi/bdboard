# Security Policy / セキュリティポリシー

## Reporting a vulnerability / 脆弱性の報告

**English**

- Please report vulnerabilities privately via GitHub Private vulnerability reporting:
  the repository's **Security** tab → **Report a vulnerability**.
- Do **not** open a public Issue or PR describing a vulnerability.
- Supported version: the latest published release (latest `bdboard` on npm).
- This is a personal project; responses are best-effort, with no guaranteed response time.

**日本語**

- 脆弱性は GitHub の Private vulnerability reporting から非公開で報告してください:
  リポジトリの **Security** タブ → **Report a vulnerability**。
- 脆弱性の内容を公開の Issue や PR に書かないでください。
- サポート対象: 最新の公開版 (npm の `bdboard` の最新)。
- 個人メンテナのプロジェクトのため、対応はベストエフォートです (応答時間の保証はありません)。
